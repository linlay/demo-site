## 安装门槛

本轮用户后续要求“你可以本地先启动给我看”，据此完成本地依赖准备与运行验证；该授权仅用于本轮启动，不取消未来变更依赖时的协作约定。

依赖只修改精确清单，不自动安装。用户在根目录运行 `pnpm install`，在 `backend/` 运行 `GOTOOLCHAIN=local go mod tidy` 后，明确要求继续，才开始依赖相关编译、测试和运行验证。基础测试未验证前不批量迁移其余领域，以免复制未经验证的事务与会话适配。
