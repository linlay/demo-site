# demo-site MCP 实施范围

## 当前范围（2026-10-13）

用户本轮明确要求移除 MCP 工具名的 `demo_` 前缀，并先完成工作台、通用审批、差旅费用和分析。新增领域 Go service、SQLite 关系表和 HTTP/MCP 共用入口，不新增依赖。按用户后续要求，将 32 个细粒度入口收敛为 11 个基础工具；可选重置使总数为 13。仅 `context:read` 的令牌只提供包含场景目录的 `context_get`，使用完整业务能力需要重新授权。

- O01：分页待办／已办、汇总、按日期汇总、差旅待办办理及来源详情；仅聚合当前已迁移的 O08／O09 来源。
- O08：读取、提交、批准、退回、撤回、重新提交、资料及完整办理历史。
- O09：差旅提交／审批／退回／重提、原有草稿保存、虚构票据元数据登记、报销核验／提交／审批／退回／补正／再提交。
- 分析：实时业务与历史样本明确分开，日期／部门／场景／状态／单据类型筛选、分组及分页，图表沿用相同来源；实时明细可钻取业务详情。
- 角色、generation、业务版本、幂等、审计及 SSE 事件在后端执行。只读动态校验在必定回滚的事务中执行，不消耗幂等键、不提交事件。
- MCP 单步工具只执行一个领域操作：待办／已办统一查询，三类单据统一查询，提交／审批／退回等由一次一个动作的 `workflow_transition` 办理。汇总、待办办理、完整报销流程由客户端重复调用基础工具组合；网站 HTTP 和 AWCP Action 合同保留。
- 其余 O/S 和 P 场景不在本轮范围；持久异步附件任务执行器仍待全栈计划后续实施，不把浏览器 Action 自动映射成工具。

业务接入实施与验证见 [接入记录](../../docs/mcp-business-progress.md)，当前工具收敛见 [收敛记录](../../docs/mcp-primitives-progress.md)。工具名称、Scope 与组合方式以 [工具目录](../../contracts/mcp/tools.json) 和 [连接文档](../../docs/mcp-deployment.md) 为准。

## 原连接验证范围（历史记录）

2026-10-03 用户明确收敛为小型安装与连接验证 demo。本次不推进企业身份体系或全量 O/S 业务迁移。

## 最终结构

一个 Go 进程提供静态前端、原 HTTP API、MCP、内置 OAuth；复用一个 SQLite 文件。保留已安装的官方 MCP SDK，不增加依赖或外部服务。

本地默认 demo/demo 登录后复制一小时 Access Token。标准客户端可走资源发现、授权服务发现、动态注册、Authorization Code + S256 PKCE、工具调用和撤销。仅公共客户端，不实现 OIDC、刷新或企业 SSO。

## 原连接验证范围

- 内置授权、登录页、Token 校验与撤销。
- 已有 Go Service 的四个读取工具及可选两个重置工具。
- 默认小数据集，已有大数据集保留为显式测试选项。
- 测试真实内置授权、MCP 协议、Scope、空间隔离、重放与撤销。
- 移除未运行的外部授权服务配置、私有凭据及安装指令。

31 场景/128 Action 清单仅说明现状，不是本轮必须迁移的功能列表。原全栈规划保留历史用途；本次只落实用户明确的小型 demo 范围。
