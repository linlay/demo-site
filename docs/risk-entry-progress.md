# 风险调查入口简化记录

日期：2026-10-16。在已有未提交改造基础上继续，修改前记录工作区状态，保留既有变更。仅修改本机前端、迁移期浏览器领域服务及文档，未修改依赖、安装依赖或远程发布。

## 实施

- 未领取的风险预警直接展示实际姓名和职责：当前数据为刘洋调查、赵敏独立复核、周宁风险监控。其他账户可通过具名按钮切换到办理人，身份仍统一写入右上角全局账户。
- 调查人员可对未领取的新预警执行“领取并填写”，直接把本人登记为调查人并展开表单；不再要求先切换风险监控人员分派。风险监控人员仍可选择在职调查人进行分派，作为折叠的可选入口。
- 原 `securities.alert.assign` Action 名称、参数、状态流转、版本、幂等和审计字段保持；新增允许调查人员领取给自己的场景，禁止借此分派给其他人或覆盖已领取预警。实际领取人的身份写入审计，不代用监控人员身份。Action 说明同步更新。
- 未领取前不展开整页不可编辑表单；领取后出现调查字段和草稿操作。预警元信息默认折叠，进度合并为调查填报、独立复核、处置归档三步。已分派、待复核、待处置事项显示具名下一步按钮。
- 草稿与正式提交校验、证据要求、独立复核及处置规则继续执行；调查人不能复核自己的结论。页面保留主要中英文文案。
- S04 仍是迁移期浏览器领域，草稿和审计由当前空间对应的浏览器 repository 保存；本轮不代表 Go/SQLite 迁移完成，也不把 S04 记录混入服务端个人待办。
